# تشغيل لوحة التحكم على جهازك (محلي، من غير سيرفر)

كل حاجة بتشتغل على جهازك: لوحة التحكم + قاعدة البيانات (ملف SQLite واحد) + الذكاء الاصطناعي
(Ollama). بعد التجهيز مش محتاج سيرفر ولا إنترنت (الإنترنت بس وقت التحديث أو تنزيل الموديل).

- العنوان: **http://127.0.0.1:8010** — مقفول على جهازك بس، محدش على نفس الشبكة يقدر يفتحه.
- المواقع اللي بتعملها بتتعاين على نفس العنوان (`/site/{slug}`) وتتصدّر zip زي ما هي.
- 3 ملفات بس هتستخدمها، كلهم في مجلد `local/`:

| ويندوز (دبل كليك) | ماك / لينكس (من الطرفية) | بيعمل إيه |
|---|---|---|
| `local\setup.bat` | `./local/setup.sh` | التجهيز — مرة واحدة (وآمن تعيده) |
| `local\start.bat` | `./local/start.sh` | تشغيل يومي — بيفتح المتصفح لوحده |
| `local\update.bat` | `./local/update.sh` | تحديث لآخر نسخة من الكود |

---

## 1) البرامج المطلوبة (مرة واحدة)

### ويندوز
افتح **PowerShell** واكتب (كل سطر لوحده):

```powershell
winget install Git.Git
winget install OpenJS.NodeJS.LTS
winget install Ollama.Ollama
```

وبعدين نزّل **Laravel Herd** (مجاني) من https://herd.laravel.com/windows وسطّبه — ده بيجيب
PHP و Composer جاهزين بكل الإضافات المطلوبة (من غير ما تعدّل `php.ini` بإيدك).

**اقفل PowerShell وافتحه تاني** بعد التسطيب (عشان يشوف البرامج الجديدة). اتأكد:
```powershell
php -v; composer -V; node -v; ollama -v
```
لازم PHP يكون **8.3 أو أحدث**.

### ماك
- Laravel Herd من https://herd.laravel.com (بيجيب PHP و Composer).
- Node.js LTS من https://nodejs.org (لو `node -v` مش شغّال بعد Herd).
- Ollama من https://ollama.com (افتحه مرة بعد التسطيب عشان يشتغل في الخلفية).

### لينكس (أوبونتو)
```bash
sudo apt install php8.3-cli php8.3-sqlite3 php8.3-mbstring php8.3-xml php8.3-zip php8.3-curl php8.3-intl composer unzip git
# Node.js LTS من https://nodejs.org أو nvm
curl -fsSL https://ollama.com/install.sh | sh
```

### الجهاز يستحمل الذكاء الاصطناعي؟
| الجهاز | الموديل المناسب | سرعة الرد تقريباً |
|---|---|---|
| كارت شاشة (NVIDIA / ماك M1 أو أحدث) | `qwen3:8b` (الافتراضي) | ثواني |
| 16 جيجا رام من غير كارت شاشة | `qwen3:8b` | 30–90 ثانية (زي السيرفر) |
| 8 جيجا رام | `qwen3:4b` — أخف وأسرع | أسرع بشوية |

لتغيير الموديل: افتح ملف `.env` وغيّر `OLLAMA_MODEL=qwen3:4b`، وبعدين `ollama pull qwen3:4b`.

## 2) نزّل الكود

```powershell
git clone https://github.com/fmffoash/barq.git C:\barq
```

⚠️ **متحطوش جوّه مجلد بيتزامن** (OneDrive / Google Drive / Dropbox — على ويندوز مجلد
`Documents` و`Desktop` غالباً على OneDrive). قاعدة البيانات ملف واحد بيتكتب فيه طول الوقت،
والمزامنة في نص الكتابة ممكن تبوّظه. `C:\barq` آمن.

على ماك/لينكس: `git clone https://github.com/fmffoash/barq.git ~/barq`

---

## 3) التجهيز — مرة واحدة

**ويندوز:** افتح `C:\barq\local` ودوس دبل كليك على **`setup.bat`**.
**ماك/لينكس:** `cd ~/barq && ./local/setup.sh`

السكريبت بيعمل كل ده لوحده (أول مرة ~5–10 دقايق + تنزيل الموديل ~5 جيجا):
1. يتأكد إن PHP 8.3+ و Composer و Node موجودين (ولو حاجة ناقصة يقولك تسطّبها إزاي).
2. `composer install` + ملف `.env` (من `.env.example`) + مفتاح التشفير.
3. `npm ci` + `npm run build` (التصميم والخطوط).
4. `php artisan barq:local-setup`: قاعدة البيانات + لينك الصور + مكتبة القوالب (300 قالب) +
   **حساب الأدمن** — هيسألك: الاسم، الإيميل، الباسورد (8 حروف على الأقل)، والباسورد تاني.
   الباسورد بيتكتب مخفي ومش بيتحفظ في أي ملف.
5. يحمّل موديل الذكاء الاصطناعي (`ollama pull qwen3:8b`) لو مش موجود.
6. في الآخر **فحص صحة** (`barq:doctor`) بيقولك كل حاجة شغّالة ولا لأ.

الأسئلة والرسايل في الطرفية بالإنجليزي (جنبها العربي) عن قصد — طرفية ويندوز مبتعرضش العربي
صح (بيطلع مقلوب).

لو ناوي تنقل شغلك من السيرفر (خطوة 5)، الأدمن اللي هتعمله هنا هيتبدّل بحساب السيرفر بتاعك،
فاكتب أي حاجة مؤقتة.

---

## 4) التشغيل اليومي

**ويندوز:** دبل كليك على **`local\start.bat`** — المتصفح بيفتح لوحده على اللوحة.
**ماك/لينكس:** `./local/start.sh`

- **سيب الشباك ده مفتوح** طول ما بتشتغل. قفله = اللوحة وقفت. (لو فتحت `start` تاني وهي
  شغالة أصلاً، بيفتحلك المتصفح بس.)
- Ollama بيشتغل لوحده مع الجهاز (أيقونته جنب الساعة على ويندوز). لو مقفول، `start` بيشغّله.
- **ويندوز بيخدم طلب واحد في نفس الوقت**: وقت ما الذكاء الاصطناعي بيكتب (ممكن دقيقة)، أي صفحة
  تانية تفتحها هتستنى لحد ما يخلص — ده طبيعي مش عطل. (ماك/لينكس بيشغّل 4 طلبات مع بعض.)

**عايزها تشتغل لوحدها مع فتح الجهاز؟** (ويندوز) دوس `Win + R` واكتب `shell:startup`، وحط
فيه **اختصار (Shortcut)** لـ`C:\barq\local\start.bat` (كليك يمين على الملف ← Show more options
← Create shortcut، وانقل الاختصار). **أيقونة على سطح المكتب:** نفس الاختصار، على Desktop.

## 5) نقل شغلك من السيرفر (مرة واحدة، اختياري)

بينقل **كل حاجة**: القوالب (بما فيها اللي عملتها بإيدك)، المشاريع، محتوى المواقع، التخصيصات
(ألوان/خطوط/أماكن العناصر)، محادثات الذكاء الاصطناعي، حساب الأدمن، والصور اللي رفعتها.
اتجرّب فعلياً من قاعدة MySQL (MariaDB) لـSQLite وكل الجداول طلعت مطابقة 100%.

**شرط:** الأوامر دي لازم تكون على السيرفر الأول — يعني الكود ده يتدمج في `main` ويتعمل
الديبلوي القياسي العادي (اللي في `CLAUDE.md`) مرة.

**أ) على السيرفر** (SSH):
```bash
cd /var/www/barq
php artisan barq:export-data --output=/root/barq-data.zip
chown -R www-data:www-data storage bootstrap/cache
```
(السطر التالت إجباري حسب قاعدة الصيانة الأولى في `CLAUDE.md` — أي `artisan` كـroot.)

**ب) على جهازك** (PowerShell على ويندوز، أو الطرفية على ماك):
```powershell
cd C:\barq
scp root@138.199.220.217:/root/barq-data.zip .
php artisan barq:import-data barq-data.zip
```
هيسألك تأكيد (اكتب `yes`) — **الاستيراد بيمسح البيانات المحلية ويحط مكانها نسخة السيرفر**
(مش دمج). بعدها ادخل بنفس **إيميل وباسورد السيرفر**.

**ج) امسح ملف النسخة من المكانين** (فيه كل بياناتك + بصمة الباسورد المشفّرة):
```bash
rm /root/barq-data.zip        # على السيرفر
```
```powershell
del C:\barq\barq-data.zip     # على جهازك
```

اختياري: لو الكود فيه قوالب مكتبة أحدث من اللي كانت على السيرفر،
`php artisan barq:seed-template-library` بيحدّثها (المشاريع نفسها مش بتتأثر).

---

## 6) التحديث (لما يتضاف كود جديد على GitHub)

اقفل شباك `start` الأول، وبعدين:
**ويندوز:** دبل كليك على **`local\update.bat`** — **ماك/لينكس:** `./local/update.sh`

ده بديل الديبلوي القياسي بتاع السيرفر بالظبط: `git pull` ← `composer install` ← `npm ci` +
`npm run build` (دايماً، مش بس لو اتغيّر CSS — قاعدة الصيانة الرابعة) ← `optimize:clear` ←
`migrate` ← فحص الصحة. **بياناتك مش بتتلمس.**

قواعد السيرفر التانية (`chown`، `reload php8.3-fpm`، كاش Cloudflare) **ملهاش لازمة على جهازك**
— مفيش www-data ولا nginx ولا Cloudflare هنا.

---

## 7) لو حاجة مش شغالة

أول حاجة دايماً، من مجلد المشروع:
```
php artisan barq:doctor
```
بيقولك كل حاجة `OK` / `WARN` / `FAIL` وجنب كل مشكلة الأمر اللي يصلّحها.

| المشكلة | الحل |
|---|---|
| الصفحات من غير أي تنسيق | `npm run build` — ولو فيه ملف `public\hot` امسحه (بيفضل لو `npm run dev` اتقفل غلط) |
| الذكاء الاصطناعي "مش متاح" | Ollama شغال؟ (`ollama list`) — الموديل متحمّل؟ (`ollama pull qwen3:8b`) |
| الصور المرفوعة مش ظاهرة | `php artisan storage:link` |
| نسيت الباسورد | `php artisan barq:create-admin` بنفس الإيميل — بيغيّر الباسورد |
| البورت 8010 مشغول | PowerShell: `$env:BARQ_PORT=8020; powershell -ExecutionPolicy Bypass -File .\local\start.ps1` (ماك/لينكس: `BARQ_PORT=8020 ./local/start.sh`) — وغيّر `APP_URL` في `.env` لنفس البورت |
| `setup` بيقول php/composer/node مش موجود | اقفل الشباك وافتح واحد جديد بعد التسطيب. لو لسه، سطّب البرنامج تاني |

---

## 8) النسخ الاحتياطي

كل بياناتك في مكانين بس: `database\database.sqlite` و `storage\app\public\` (الصور).
أسهل نسخة احتياطية كاملة في ملف واحد:
```
php artisan barq:export-data
```
بيحطها في `storage\app\backups\` — انسخها لمكان تاني (فلاشة/درايف). للاسترجاع:
`php artisan barq:import-data <الملف>`.

---

## 9) السيرفر بعد كده

النسخة اللي على السيرفر بتفضل شغالة زي ما هي لحد ما تقرر غير كده — الكود ده مش بيلمسها. قفلها
(لو حبيت) بيفضّي رام كتير لـTafra ERP (Ollama بس كان بياخد 2.5–5 جيجا وقت التوليد)، بس دي خطوة
يدوية منفصلة على السيرفر، مش جزء من التجهيز ده.

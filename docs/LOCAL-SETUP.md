# تشغيل لوحة التحكم على جهازك (زي أي برنامج، من غير سيرفر)

كل حاجة بتشتغل على جهازك: لوحة التحكم + قاعدة البيانات (ملف واحد) + الذكاء الاصطناعي
(Ollama). بعد التسطيب مش محتاج سيرفر ولا إنترنت (الإنترنت بس وقت التسطيب والتحديث).

- بتفتحها من **أيقونة على سطح المكتب** اسمها **"لوحة المواقع"** — المتصفح بيفتح لوحده عليها.
- العنوان: **http://127.0.0.1:8010** — مقفول على جهازك بس، محدش على نفس الشبكة يقدر يفتحه.
- المواقع اللي بتعملها بتتعاين وتتصدّر zip زي ما كانت على السيرفر بالظبط.

---

## ويندوز — 3 خطوات

### 1) نزّل ملف التسطيب
ملف واحد اسمه **`install-windows.bat`** (موجود في الريبو في `local/install-windows.bat`، أو
من الرابط ده: https://raw.githubusercontent.com/fmffoash/barq/main/local/install-windows.bat
— كليك يمين ← Save link as / حفظ الرابط باسم).

### 2) دبل كليك عليه
- لو ظهرت رسالة زرقا **"Windows protected your PC"**: دوس **More info** ← **Run anyway**
  (ده تحذير عادي لأي ملف متحمّل من النت).
- لو ويندوز سأل **"Do you want to allow this app to make changes"**: دوس **Yes** (بيحصل
  وقت تسطيب Git والحاجات اللي PHP محتاجها).
- هيسألك 4 أسئلة بس (حساب الدخول للوحة): **الاسم، الإيميل، الباسورد (8 حروف على الأقل)،
  والباسورد تاني**. الباسورد مش هيبان وانت بتكتبه — ده طبيعي، اكتبه ودوس Enter.
- سيبه يكمّل — أول مرة ممكن ياخد **من 15 دقيقة لساعة** حسب سرعة النت (بينزّل حوالي 7 جيجا،
  أغلبها موديل الذكاء الاصطناعي). في الآخر هتلاقي **Done** — دوس أي زرار عشان الشباك يقفل.

### 3) افتح "لوحة المواقع" من سطح المكتب
دبل كليك على الأيقونة ← المتصفح بيفتح على صفحة الدخول ← ادخل بالإيميل والباسورد اللي كتبتهم.

**وقت الشغل:** فيه شباك أسود صغير بيتفتح متصغّر في شريط المهام — **ده البرنامج نفسه**. سيبه
مفتوح طول ما بتشتغل؛ قفله = اللوحة وقفت. لو دوست على الأيقونة وهي شغالة أصلاً، بيفتحلك
المتصفح بس.

### إيه اللي التسطيب بيعمله بالظبط؟
1. يسطّب **Git** (لو مش موجود) وينزّل الكود في **`C:\barq`**.
2. ينزّل نسخة خاصة بالتطبيق من **PHP** و**Composer** و**Node.js** جوّه `C:\barq\.runtime`
   (مش بيسطّب حاجة على الويندوز كله، ولو عندك PHP 8.3+ أو Node أصلاً بيستخدمهم). كل تنزيل
   بيتأكد من سلامته (checksum) قبل ما يستخدمه.
3. يجهّز قاعدة البيانات + مكتبة الـ300 قالب + حساب الدخول.
4. يسطّب **Ollama** وينزّل موديل الذكاء الاصطناعي (`qwen3:8b`، حوالي 5 جيجا).
5. يحط أيقونة **"لوحة المواقع"** على سطح المكتب وفي قايمة Start.

لو أي خطوة فشلت (النت قطع مثلاً)، **شغّل `install-windows.bat` تاني** — بيكمّل من مكان ما وقف
ومش بيكرّر اللي خلص.

**عايزها تشتغل لوحدها مع فتح الجهاز؟** دوس `Win + R` واكتب `shell:startup` ← انسخ أيقونة
"لوحة المواقع" من سطح المكتب لجوّه الفولدر ده.

## الجهاز يستحمل الذكاء الاصطناعي؟

| الجهاز | الموديل المناسب | سرعة الرد تقريباً |
|---|---|---|
| كارت شاشة (NVIDIA / ماك M1 أو أحدث) | `qwen3:8b` (الافتراضي) | ثواني |
| 16 جيجا رام من غير كارت شاشة | `qwen3:8b` | 30–90 ثانية (زي السيرفر) |
| 8 جيجا رام | `qwen3:4b` — أخف وأسرع | أسرع بشوية |

لتغيير الموديل: افتح `C:\barq\.env` بـNotepad وغيّر `OLLAMA_MODEL=qwen3:4b`، وبعدين في
PowerShell: `ollama pull qwen3:4b`.

**ويندوز بيخدم طلب واحد في نفس الوقت**: وقت ما الذكاء الاصطناعي بيكتب (ممكن دقيقة)، أي صفحة
تانية تفتحها هتستنى لحد ما يخلص — ده طبيعي مش عطل. (ماك/لينكس بيشغّل 4 طلبات مع بعض.)

## ماك / لينكس

1. سطّب: PHP 8.3+ و Composer (ماك: Laravel Herd من https://herd.laravel.com — لينكس:
   `sudo apt install php8.3-cli php8.3-sqlite3 php8.3-mbstring php8.3-xml php8.3-zip php8.3-curl composer git`)،
   Node.js LTS (https://nodejs.org)، و Ollama (https://ollama.com).
2. `git clone https://github.com/fmffoash/barq.git ~/barq && cd ~/barq && ./local/setup.sh`
3. كل يوم: `./local/start.sh` (بيفتح المتصفح لوحده، Ctrl+C يقفل).

⚠️ متحطش الفولدر جوّه مجلد بيتزامن (iCloud / OneDrive / Dropbox) — قاعدة البيانات ملف واحد
بيتكتب فيه طول الوقت، والمزامنة في نص الكتابة ممكن تبوّظه.

## نقل شغلك من السيرفر (مرة واحدة، اختياري)

بينقل **كل حاجة**: القوالب (بما فيها اللي عملتها بإيدك)، المشاريع، محتوى المواقع، التخصيصات
(ألوان/خطوط/أماكن العناصر)، محادثات الذكاء الاصطناعي، حساب الدخول، والصور اللي رفعتها.
اتجرّب فعلياً من قاعدة MySQL (MariaDB) لـSQLite وكل الجداول طلعت مطابقة 100%.

**شرط:** الكود ده لازم يكون على السيرفر الأول (الديبلوي القياسي العادي اللي في `CLAUDE.md`).

**أ) على السيرفر** (SSH):
```bash
cd /var/www/barq
php artisan barq:export-data --output=/root/barq-data.zip
chown -R www-data:www-data storage bootstrap/cache
```
(السطر التالت إجباري حسب قاعدة الصيانة الأولى في `CLAUDE.md` — أي `artisan` كـroot.)

**ب) على جهازك** — افتح PowerShell:
```powershell
cd C:\barq
scp root@138.199.220.217:/root/barq-data.zip .
.\local\artisan.bat barq:import-data barq-data.zip
```
هيسألك تأكيد (اكتب `yes`) — **الاستيراد بيمسح البيانات المحلية ويحط مكانها نسخة السيرفر**
(مش دمج). بعدها ادخل بنفس **إيميل وباسورد السيرفر**.

**ج) امسح ملف النسخة من المكانين** (فيه كل بياناتك + بصمة الباسورد المشفّرة):
```bash
rm /root/barq-data.zip        # على السيرفر
```
```powershell
del C:\barq\barq-data.zip     # على جهازك
```

## التحديث (لما يتضاف كود جديد على GitHub)

اقفل شباك البرنامج الأول، وبعدين دبل كليك على **`C:\barq\local\update.bat`** (ماك/لينكس:
`./local/update.sh`). أو ببساطة شغّل `install-windows.bat` تاني — بيعمل نفس الحاجة.

ده بديل الديبلوي القياسي بتاع السيرفر: `git pull` ← `composer install` ← `npm ci` +
`npm run build` ← `optimize:clear` ← `migrate` ← فحص الصحة. **بياناتك مش بتتلمس.** قواعد
السيرفر التانية (`chown`، `reload php8.3-fpm`، كاش Cloudflare) **ملهاش لازمة على جهازك**.

## لو حاجة مش شغالة

أول حاجة دايماً — دبل كليك على **`C:\barq\local\doctor.bat`** (ماك/لينكس:
`php artisan barq:doctor`). بيقولك كل حاجة `OK` / `WARN` / `FAIL` وجنب كل مشكلة الحل.

| المشكلة | الحل |
|---|---|
| الصفحات من غير أي تنسيق | شغّل `update.bat` (بيعيد بناء التصميم) |
| الذكاء الاصطناعي "مش متاح" | Ollama شغال؟ (أيقونته جنب الساعة) — الموديل متحمّل؟ (`ollama pull qwen3:8b`) |
| نسيت الباسورد | PowerShell في `C:\barq`: `.\local\artisan.bat barq:create-admin` بنفس الإيميل — بيغيّر الباسورد |
| البورت 8010 مشغول | PowerShell في `C:\barq`: `$env:BARQ_PORT=8020; .\local\start.bat` — وغيّر `APP_URL` في `.env` لنفس البورت |
| التسطيب وقف في النص | شغّل `install-windows.bat` تاني — بيكمّل من مكان ما وقف |
| الأنتي فيروس مسح `php.exe` | ضيف `C:\barq` للاستثناءات وشغّل `install-windows.bat` تاني |

## النسخ الاحتياطي

كل بياناتك في مكانين بس: `C:\barq\database\database.sqlite` و `C:\barq\storage\app\public\`
(الصور). أسهل نسخة كاملة في ملف واحد — PowerShell في `C:\barq`:
```powershell
.\local\artisan.bat barq:export-data
```
بيحطها في `storage\app\backups\` — انسخها لمكان تاني (فلاشة/درايف). للاسترجاع:
`.\local\artisan.bat barq:import-data <الملف>`.

## السيرفر بعد كده

النسخة اللي على السيرفر بتفضل شغالة زي ما هي لحد ما تقرر غير كده — التسطيب ده مش بيلمسها.
قفلها (لو حبيت) بيفضّي رام كتير لـTafra ERP (Ollama بس كان بياخد 2.5–5 جيجا وقت التوليد)، بس
دي خطوة يدوية منفصلة على السيرفر.

# لوحة تحكم — أداة شخصية لبناء صفحات الهبوط

أداة خاصة (أدمن + يوزرات بيعملهم الأدمن): مكتبة ~600 قالب (منها تصميمات 3D) + محتوى (يدوي أو بالذكاء الاصطناعي المحلي Ollama) ← موقع
كامل قابل للمعاينة والتصدير كملفات ثابتة. Laravel 13 + Blade + Tailwind v4.

## التشغيل على جهازك

**ويندوز:** نزّل `local/install-windows.bat` ودوس عليه دبل كليك — بيسطّب كل حاجة لوحده
(PHP/Node/Composer نسخة خاصة بالتطبيق + Ollama والموديل) وبيحط أيقونة **"لوحة المواقع"** على
سطح المكتب. **ماك/لينكس:** `./local/setup.sh` مرة واحدة، وبعدين `./local/start.sh`.

الدليل الكامل خطوة بخطوة: **[docs/LOCAL-SETUP.md](docs/LOCAL-SETUP.md)** — وفحص الصحة:
`local\doctor.bat` (ويندوز) أو `php artisan barq:doctor`.

## للمطوّرين

قوالب الملف المطوّرة: 98 قالبًا إضافيًا باسم **موشن 3D** داخل التصنيفات الحالية. لتجهيزها:
`php artisan migrate --force` ثم `php artisan barq:seed-motion-templates`.
الأمر آمن للتكرار ويحافظ على تعديلات القوالب والمشاريع القائمة، و`barq:local-setup` ينفّذه تلقائيًا.
المعاينة والتحرير والتصدير الثابت يدعمون الصور والحركة والخطوط المحلية؛ الحركة تتوقف داخل المحرر وتحترم تقليل الحركة.

توثيق المعمار وقواعد الشغل كلها في [CLAUDE.md](CLAUDE.md)، والخطة والحالة في [ROADMAP.md](ROADMAP.md). لايف على `barq.tafraos.com`. النشر على سيرفر (القديم):
[deploy/DEPLOYMENT.md](deploy/DEPLOYMENT.md). التستات: `php artisan test` (محتاج `npm run build` قبلها).
